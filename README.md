# 🏛️ Barangay Unang Sigaw E-Services Web Portal

A lightweight, high-performance, **database-less** Local Government Unit (LGU) Information System designed specifically for the community and administration of **Barangay Unang Sigaw, Quezon City**. 

Patterned closely after the architectural aesthetics and usability paradigms of the **Quezon City e-Services platform**, this application runs completely client-side. It utilizes the browser's persistent `localStorage` to emulate a fully functional relational database backend—making it highly transportable and perfect for rapid offline prototypes, school defenses, or lightweight edge deployment.

---

## 🎨 System Highlights & Features

### 👤 Citizen / Resident Facing Portal
*   **Branded Local Identity:** Tailored theme matching the official historical seal of Barangay Unang Sigaw using *Deep Revolution Blue, Katipunan Crimson, and Sunburst Gold*.
*   **Secure Unified Login:** Dual-mode authentication panel handling both standardized Philippine mobile identifier formats (`09XXXXXXXXX`) and official admin emails.
*   **Dynamic Resident Digital ID:** Generates a real-time virtual identity card pulling constituent parameters dynamically, complete with sector badges (Senior, PWD, Solo Parent), an active status loop, and a verification mock QR matrix block.
*   **In-Dashboard Profile Photo Engine:** Fully interactive photo slot allowing residents to instantly click, upload, and permanently compress their 2x2 image into browser memory using secure client-side Base64 serialization strings.
*   **Interactive E-Services Modals:** Built-in frosted frosted-glass overlay forms triggering custom document applications (Barangay Clearance, Certificate of Indigency) on demand.
*   **Application Progress Tracker:** Integrated tracker retrieving persistent transactional arrays to update users on their certificate log states (`Pending Approval`).

### 💼 Administration Control Terminal
*   **Constituent Verification Ledger:** A secure desk ledger mapping real-time constituent profiles committed to the local workspace memory database.
*   **Console Analytics Overview:** Dynamic metric panels updating total population entries and tracking current verification backlogs in real-time.
*   **Administrative Authorization Verification:** Strict row-level verification gate routing unauthenticated direct link intrusions instantly back to the central index portal.

## 🚀 Local Development & Maintenance

### 1. Launching Local Server Execution
This application reads and compiles localized system properties. To prevent data separation boundaries generated by direct browser file rendering (`file:///C:/...`), it is highly recommended to run the code inside a local server configuration:
*   Open the root workspace directory inside **Visual Studio Code**.
*   Right-click `index.html` and select **"Open with Live Server"** (or use the status bar `Go Live` command).
*   The application will deploy on port loop: `http://127.0.0`.

### 🧹 Wiping/Resetting Your Local Data Store
Because data inputs populate the computer browser's internal data storage block permanently, you can safely trigger a clean wipe state wipe back to just the filler data at any time. Open the browser **Developer Tools Console (`F12` -> Console)** and execute:
```javascript
localStorage.clear();
location.reload();
```

## 🌐 Live Public Hosting Deployment (GitHub Pages)

This ecosystem is fully optimized for immediate, **zero-cost public distribution** via GitHub Pages:
1. Push this complete project folder structure cleanly up to a **Public GitHub Repository**.
2. Go to the repository **⚙️ Settings** page tab.
3. Access the **Pages** panel section from the left navigation submenus.
4. Set the **Branch** target dropdown to **`main` (or `master`)**, leave the directory targeting set to **`/(root)`**, and click **Save**.
5. Your system becomes globally interactive at: `https://<your-username>.github.io/<repository-name>/`.
